## About

I build machine learning systems that make biological data legible to a machine — image volumes with no labels, genomes where the signal is buried in a million features, RNA that folds into shapes nobody has annotated.

Right now I'm a **Theory@EMBL Fellow** at the European Molecular Biology Laboratory in Heidelberg, developing unsupervised representation learning for 3D expansion microscopy. Before that: AlphaFold pipelines at the Max Planck Institute, an RNA structure meta-server at IIMCB Warsaw, and a publication in *Bioinformatics Advances* on explainable ML for antimicrobial resistance.

I care about the parts that ML-for-biology work usually skips — reproducible pipelines, interpretable models, and code another researcher can actually run. Four countries in six years, one problem.

## Featured Projects

<details>
<summary><b>Unsupervised Representation Learning for 3D Expansion Microscopy</b> — EMBL Heidelberg</summary>

<br/>

A modality-agnostic deep learning framework that extracts morphological features directly from raw U-ExM image volumes. No manual segmentation. No labelled training set.

| | |
|:---|:---|
| **Stack** | PyTorch · VAEs · Self-supervised learning · 3D image processing |
| **Scale** | Ultrastructural phenotyping across free-living unicellular eukaryotes spanning the tree of life |
| **Approach** | Latent-space morphology extraction from unlabelled volumetric data |
| **Output** | Quantitative cell biology at scale, transferable across imaging modalities |
| **Status** | Active — May 2026 to present |
| **Repository** | Ongoing research |

Manual segmentation is the bottleneck in quantitative microscopy: it does not scale, and it bakes the annotator's assumptions into the result. This framework removes the step entirely, learning morphological representations directly from raw volumes. The current application is mapping centrin structural diversity across the eukaryotic tree, a comparison that would be intractable by hand.

</details>

<details>
<summary><b>Explainable ML Pipeline for Antimicrobial Resistance</b> — Published, <i>Bioinformatics Advances</i></summary>

<br/>

A resistance-prediction pipeline for *Pseudomonas aeruginosa* with SHAP-based interpretability surfacing the genomic features that actually drive resistance.

| | |
|:---|:---|
| **Stack** | Python · scikit-learn · SHAP · Genomic feature engineering |
| **Performance** | 90%+ prediction accuracy |
| **Interpretability** | SHAP attribution across genomic determinants |
| **Impact** | Peer-reviewed publication, Oxford Academic, August 2025 |
| **Publication** | [10.1093/bioadv/vbaf190](https://doi.org/10.1093/bioadv/vbaf190) |

A resistance classifier that cannot explain itself is useless to the clinician who has to act on it. The interpretability layer was the point of the work rather than an add-on: SHAP attribution over the genomic feature set identifies which determinants drive each prediction, turning a score into a hypothesis a microbiologist can test.

</details>

<details>
<summary><b>RNA 3D Structure Prediction Meta-Server</b> — IIMCB Warsaw</summary>

<br/>

An ensemble meta-server combining RosettaFoldNA and DRFold2 predictions into composite structural inputs for SimRNA.

| | |
|:---|:---|
| **Stack** | Python · RosettaFoldNA · DRFold2 · SimRNA · HPC |
| **Scale** | High-throughput structural bioinformatics workflow |
| **Performance** | 40% reduction in end-to-end processing time through parallelisation |
| **Impact** | ERASMUS+ research placement, Polish Academy of Sciences |
| **Repository** | Institutional |

Single-predictor RNA structure pipelines inherit the failure modes of whichever model you picked. Ensembling two independent predictors into composite inputs for SimRNA hedges that risk, and parallelising the workflow across HPC nodes made the ensemble cheap enough to be the default rather than a luxury.

</details>

<details>
<summary><b>Transcriptomics × Structural Biology Integration</b> — Max Planck Institute, Göttingen</summary>

<br/>

Automated AlphaFold structure-prediction pipelines evaluating the functional impact of transcriptomic change, in Dr. Peter Lenart's lab.

| | |
|:---|:---|
| **Stack** | AlphaFold · Python · Transcriptomics · Multi-omics |
| **Scope** | 3′ UTR regulatory analysis during oocyte maturation |
| **Methods** | Motif discovery · RNA secondary structure · Pathway enrichment |
| **Impact** | Structural consequence prediction for differentially expressed transcripts |
| **Repository** | Institutional |

Differential expression tells you a transcript changed. It does not tell you whether the protein still folds. This pipeline closes that gap by running structure prediction automatically over transcriptomic hits, alongside regulatory analysis of the 3′ UTR landscape during oocyte maturation.

</details>

<details>
<summary><b>Castor — CRISPR Guide RNA Design Tool</b> — University of Göttingen</summary>

<br/>

A full-stack tool that takes a FASTA file and returns ranked, feature-annotated gRNA candidates.

| | |
|:---|:---|
| **Stack** | Python · XGBoost · Random Forest · ViennaRNA · Streamlit |
| **Model** | Stacking ensemble regressor over structural and one-hot sequence features |
| **Features** | Minimum free energy · Base-pairing probability · Ensemble energy · Helical properties |
| **Scope** | Authentication, project management, interactive Plotly visualisations, CSV export |
| **Role** | Project lead — ML development and database curation |
| **Repository** | [CRISPR-Guide-RNA-Design-Tool](https://github.com/bsa674/CRISPR-Guide-RNA-Design-Tool) |

Guide RNA selection is usually a spreadsheet exercise with a scoring heuristic attached. Castor replaces the heuristic with a stacking ensemble trained on curated efficacy data, then annotates each candidate with the thermodynamic features driving its score — so a wet-lab researcher gets both a ranking and a reason.

</details>
